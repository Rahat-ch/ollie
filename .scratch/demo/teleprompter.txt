The third thing I learned is about using AI to grade AI. Some stuff code just can't check, like is this story actually readable for a six-year-old? So another AI grades it.

So I told the grader about it and re-graded everything. And under the same grader, the new model's stories actually scored higher. So it wasn't a worse writer. It was a stricter grader.

# 09: Onboarding, Parent Gate, and Parent Area

**What to build:** A Parent opens the app for the first time and sets up a Profile in under a minute: 'What should Ollie call you?' for the Nickname, an Avatar colour, a Theme from six illustrated choices, and a one-screen note that the Nickname is sent to generate Stories and audio and nothing else leaves the device. A press-and-hold Parent Gate opens the Parent Area, which shows Mastery per Skill and placeholders for Summaries, Powers, and Ollie's Notebook.

**Blocked by:** 08 Play a Session

**Status:** ready-for-agent

- [ ] Onboarding completes in four screens and hands over to Ollie speaking the Nickname (text for now)
- [ ] The disclosure line about the Nickname is present verbatim in onboarding
- [ ] The Parent Gate requires a continuous press of about three seconds and cannot be opened by tapping
- [ ] The Parent Area shows the Knowledge Estimate and Mastered state for all seven Skills

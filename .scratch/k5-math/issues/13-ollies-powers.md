# 13: Ollie's Powers

**What to build:** When the Learner Masters counting on, make-a-ten, unknown addend, or Unit 3, the Session's headline celebration shows Ollie learning a Power: Count-On Flight, Make-Ten Magic, Missing Number Detective, Story Solver. From then on, every matching Problem shows Ollie using it: wing beats along the number line, filling and splitting on the ten-frame, a magnifying-glass search for the missing part, richer Story variants. Powers appear on the Path, in the Parent Area, and by name in the Parent Summary. Powers are never lost and never bought.

**Blocked by:** 08 Play a Session, 10 Unit 3 Stories

**Status:** ready-for-agent

- [ ] Mastery of the named Skill or Unit awards its Power exactly once and it persists
- [ ] Each Power has its own animation on matching Problems, built to the character sheet poses
- [ ] The Power celebration replaces the ordinary Session celebration on the Session it is earned
- [ ] Story Solver switches Unit 3 to the richer Story variant set
- [ ] Path, Parent Area, and Parent Summary all show Powers by name; Badges do not exist anywhere

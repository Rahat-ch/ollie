**What to build:** Before any screen is built, the look is settled on a design canvas: palette, type, spacing, Ollie's character sheet (four base states and the four Power poses), a flat, warm, hand-tuned illustration style that does not read as AI-generated, and the core screens at tablet landscape: home with Path and Play, the Session screen with number pad and ten-frame, the celebration, onboarding, and the Parent Area with Ollie's Notebook. Produced with the design canvas skill so the user can adjust it visually; the UI tickets build to it.

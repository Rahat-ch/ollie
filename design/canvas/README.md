# Design canvas sources

The design direction for ticket 02 lives here as Design Component artboards (`*.dc.html`) plus `canvas.json` (layout, pages, launch view). The published canvas the user reviews is at https://claude.ai/code/artifact/332d6f58-2ff2-4c31-b254-1332f2527629.

- `Main.dc.html` is the Home screen (titled "Home" on the canvas). The other screens are Session, Celebration, Onboarding, ParentArea, Notebook; `Tokens.dc.html` is the token sheet and `Ollie.dc.html` the character sheet.
- `AltCoolNight.dc.html` and `AltBoldPoster.dc.html` are deliberately rough alternates on the "Alternates" page, kept so the choice is visible.
- Ollie poses are referenced by bare filename and come from `public/ollie/`.
- The seeded page (`ollie-design-direction.html`) is generated by the design skill's helper and is gitignored; regenerate it from these sources rather than editing it. The artboards reference the Ollie poses by bare filename, so the seed must pass every `public/ollie/*.svg` as an `--image` alongside the artboards and `canvas.json`; the images are not copied into this directory.

The written source of truth is `docs/design/direction.md`; the app consumes tokens from `src/app/tokens.css` (mirrored in `src/design/tokens.ts`).

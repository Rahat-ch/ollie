# Eval Runs

Every `pnpm eval` writes one dated JSON report here, named by its UTC time (`2026-09-11T23-05-00Z.json`), and regenerates `convergence.svg` from that file. `pnpm eval:chart` redraws the chart from the latest report, or from any earlier one with `--report`. Reports are committed so a number in the write-up or the video can be traced to the run that produced it. Each report says which Generation ran the Coach (`coach.generation`: `fake`, or the model id); the chart says so in its subtitle.

The run plays the six Simulated Learners (`src/evals/learners.ts`) for 20 Sessions each under the Coach and under the Baseline on identical seeds. The convergence section records, per Learner and per planner, the Session in which each Skill became Mastered, the first-try rate, and the share of Problems in the target accuracy band (a true first-try chance of 0.7 to 0.9). The hypotheses section scores the Coach run: for each planted weakness, the Session after which a supported Hypothesis first named it in its own words (crossing ten, missing addend), never just the Skill; false positives, supported Hypotheses naming a weakness the Learner does not have; Evidence Integrity over every citation in every Notes the Coach wrote, rejected attempts included, so an invented Problem ID counts even though the engine refused it; the cited ID must exist in the Log so far and its Assistance State must agree with the claim (a difficulty claim, "misses", "needs a Hint", cites Problems that were not first-try correct; a strength claim, "solid", "no Hints", ones that were; a refuted Hypothesis or a claim with no polarity is checked for the ID only); and how many Plans came from the Coach, from a retry, or from the Baseline fallback. The two held-out Learners, change-unknown weakness and fast fatigue, are never used to tune a prompt; every report flags them and scores the tuning and held-out splits separately. Simulated Learners only; never a real child's data.

The first report, `2026-09-11T00-16-16Z.json`, is from ticket 05 and has the Baseline alone; the chart refuses it with a message, and its numbers are reproduced byte for byte in every later report's `convergence.baseline`.
